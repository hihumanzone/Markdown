Features & Syntax

  • GitHub Flavored Markdown: Headings, tables, checklists, blockquotes, syntax-highlighted code blocks.
  • LaTeX Math Support: Inline math using $E = mc^2$ or \( \alpha + \beta \); display math using $$ \sum_{i=0}^n i $$ or \[ \text{H}_2\text{O} \].
  • Code Syntax Highlighting: Prism.js syntax coloring, numbered lines, and one-click copy buttons for multiple languages.
  • Export Capabilities: Print / Save as PDF with custom filenames, export as Markdown (.md), or high-res PNG image.
  • My Library & History: Categorize sections into folders, tag with color labels, backup/restore JSON, and access recent history items.
